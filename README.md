# HockeyPredictions
Code for predicting the performance of NHL teams in the playoffs

The code generate_team_data.py generates the data used for NHL playoff prediction. It generates the CSV files in the team_stats folder and the playoff_results.csv file. The CSV files in the team_stats folder are the inputs for the prediction model and the playoff_results are the team's performance in the playoffs for training the model.

The code playoff_predictor.py generates the two pdf plots in the repo representing the accuracy of a random forest model. These plots are generated by predicting the playoff performance of each team given the model output and then comparing them to the actual playoff performance. The difference in prediction and true output is converted into an error for the given year. Errors are calculated for model prediction, naive prediction where teams perform based on their final standings and a random prediction. Errors for the year y were calculated by training the model on data from the year 2005 to y - 1 and then making the prediction on year y.

The plot prediction-naive_estimate_score_difference.pdf shows how the model predictions compare with the naive predictions. Data points in the positive indicate that errors from the model prediction are greater than for the naive prediction and so the model performed worse for that year. Likewise, data points in the negative indicate the model prediction was better than the naive prediction. Looking at the graph, there are a comparable number of positive and negative data points indicating the two methods are camparably effective estimation methods for team performance in the playoffs.

The plot prediction-random_estimate_score_difference.pdf compares the model predictions with random predictions instead of the naive prediction. Here there are noticeably more negative points than positive points and the axis scales are larger than in the naive predictions plot. Hence the data driven prediction method is better than random predictions.

This experiment featured mixed success. It was successful in that the model was able to out perform the random predictions but unfortunate that it was not able to outperform the naive prediction.
